# Phase 26J — Local Dry-Run CLI

Phase 26J adds a local dry-run CLI/helper layer for the parallel learning stack.

It lets you take an exported alignment artifact folder and run:

```text
load export pack → quality gates → training dry-run planner → JSON summary
```

It still does **not** train anything.

## What was added

### `backend/dialogues/learning_dry_run_cli.py`

Main helpers:

- `infer_alignment_format(...)`
- `infer_dataset_split(...)`
- `load_alignment_pack_from_mapping(...)`
- `load_alignment_pack_from_directory(...)`
- `run_local_dry_run(...)`
- `run_local_dry_run_from_directory(...)`
- `build_arg_parser(...)`
- `main(...)`

### `tests_dialogues/test_learning_dry_run_cli.py`

Offline tests cover:

- filename → alignment format inference
- filename → split inference
- manifest requirement
- mapping loader
- directory loader
- quality + planner dry-run result
- explicit `no_training_executed=True`

## Expected artifact folder

The folder should contain files generated by `AlignmentExportPack.as_files()`:

```text
manifest.json
trace_sft.train.jsonl
dpo.train.jsonl
nemo_dpo.train.jsonl
reward_pairs.train.jsonl
process_sft.train.jsonl
```

Not all JSONL formats are required, but `manifest.json` is required.

## CLI usage

From repo root:

```powershell
python -m backend.dialogues.learning_dry_run_cli .\path\to\alignment_export --quality-policy exploratory --planner-policy exploratory --pretty
```

Strict mode:

```powershell
python -m backend.dialogues.learning_dry_run_cli .\path\to\alignment_export --quality-policy strict --planner-policy conservative --pretty
```

## Output shape

The CLI prints JSON with:

```json
{
  "export": {...},
  "quality": {...},
  "plan": {...},
  "plan_json": {...},
  "no_training_executed": true
}
```

## Safety model

This phase does not:

- train models
- fine-tune models
- call providers
- change CED state
- modify `ced.py`
- change prompts
- change routing
- change scoring
- change ratification

It only loads exported artifacts, evaluates quality, and creates a dry-run plan.

## Why this matters

Before this phase, the learning stack had strong components, but no simple local command to inspect an export pack.

Now the flow is usable:

```text
export artifacts → run CLI → see PASS/WARN/FAIL → see READY/INSPECT_ONLY/BLOCKED training families
```

This is the final practical bridge before real training adapters.
