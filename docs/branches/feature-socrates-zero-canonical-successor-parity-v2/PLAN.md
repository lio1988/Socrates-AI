pass every required regression and frozen-lineage check.

## Stop conditions

Stop before the aggregate if any approved orthogonal construction is not
orthogonal, any runtime semantic change is required, any frozen blob or
historical hash changes, or expected evaluator truth enters a runtime object.
After the aggregate, preserve the artifact and stop without tuning on any
falsification or replay divergence.
