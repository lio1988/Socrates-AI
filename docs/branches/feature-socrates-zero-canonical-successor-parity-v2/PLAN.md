## Stop conditions before the aggregate

Stop if any orthogonal probe changes a second undeclared independent input, any
target guard is not reachable with every earlier guard preserved, any observed
literal/vector/stage/submission evidence differs, expected truth enters a
runtime closure, any advisory field requires later validation, any frozen core
or historical/predecessor lock differs, any runtime semantic change is needed,
or any live/provider/model/tool call occurs.

## Stop conditions after the aggregate

The first artifact is immutable. On any threshold failure, preserve it as
`FALSIFIED` and stop without tuning, retry, replay, or expectation changes. On a
supported first artifact, any reverse-replay semantic/ID/byte/SHA divergence is
also a permanent falsification and blocks replay-lock publication.
