# Branch: feature/socrates-zero-canonical-observability-v1

## Purpose

Test exactly one hypothesis: authoritative typed epistemic distinctions already
owned by CED/Hybrid can be preserved in an opt-in SearchState/projection v1
without inference, prose interpretation, future information, or new authority.

## Success criterion

An additive immutable v1 projection exposes at least one meaningful canonical
distinction that SearchState v0 cannot structurally expose, with deterministic
identity, source provenance, temporal isolation, fail-closed validation, and no
change to any v0 or production path.

## Scope

The branch may add v1 observation contracts, a trusted CED-side read-only v1
projector, structural science tests, an observability ADR/report, and durable
documentation. The frozen v0 SearchState remains embedded for compatibility and
replay identity; the new typed views remain owned semantically by their
canonical Hybrid records and governing claim assessments.

Phase 6 is complete and the hypothesis is supported. See
[`docs/SOCRATES_ZERO_CANONICAL_OBSERVABILITY_V1.md`](../../SOCRATES_ZERO_CANONICAL_OBSERVABILITY_V1.md)
for the authority matrix, exact alias evidence, leakage analysis, limitations,
and final verification record.

Phase 6.5 is a documentation-only Value v1 decision gate. It changes no core
code and records exactly one decision: a penalty-only deterministic Value v1
implementation experiment is earned on a new branch and new frozen evaluation.
See
[`docs/SOCRATES_ZERO_VALUE_V1_DECISION_GATE.md`](../../SOCRATES_ZERO_VALUE_V1_DECISION_GATE.md).

## Non-goals

No Value, Policy, Greedy, BestOfN, PUCT, successor, benchmark, depth-two,
provider, shadow, live-call, learning, RL, CED execution, release, or production
wiring change is authorized on this branch. Phase 6.5 designs but does not
implement Value v1.
